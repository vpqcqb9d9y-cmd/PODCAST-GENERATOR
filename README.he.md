## סקירה מהירה
- מקבלים תמלול (SRT/TXT) ומטא-דאטה ראשוני → יוצרים דיאלוג בין שני מנחים (Roee & Noa).
- ממירים את הדיאלוג לפודקאסט בעברית, מציגים גלריה של תוצרים (אודיו, וידאו, PPTX, Story).

## דרישות מוקדמות
1. Python 3.9 ומעלה
2. FFmpeg מותקן ונמצא ב-PATH (`ffmpeg -version`)
3. Azure OpenAI (GPT-4o/4-turbo) + Azure Speech Services
4. (אופציונלי) מפתח Gemini ל-bootstrap של מטא-דאטה בסגנון NotebookLM

## התקנה והגדרת סביבה
```bash
git clone https://github.com/<org>/podcast-generator.git
cd podcast-generator
pip install -e .[dev]
```

1. העתקו `.env.example` ל-`.env` ומלאו endpoint+keys של Azure OpenAI/Speech.
2. הגדירו קבצי intro/outro (אם יש) תחת `assets/audio/`.
3. ודאו שהמסלולים ב-`OUTPUT_BASE_DIR` ו-`VOICE_PROFILES_PATH` מתאימים לסביבות שלכם.

## הרצה מה-CLI
```bash
python -m scripts.generate_podcast \
  data/sample_transcript.txt \
  data/sample_metadata.json \
  --include-visuals \
  --voice-profile classic \
  --export-ppt
```

דגלים שימושיים: `--dry-run`, `--skip-cache`, `--force`, `--material`, `--url`, `--output-dir`.

### 🎙️ Voice Lab (שיכפול קול מיידי)
- לשונית חדשה לצד ה-Control Panel: **"🎙️ Voice Lab"**.
- העלו/בחרו קובץ WAV/MP3 נקי באורך 60 שניות.
- לחצו **Clone with ElevenLabs** – המערכת תשלח ל-Instant Voice Cloning ותחזיר `voice_id`.
- הפרופיל **"Custom"** נשמר אוטומטית ב-`config/voice_profiles.json` (שני הדוברים למודל `eleven_multilingual_v2`).
- מציג **יתרת תווים** מ-`v1/user/subscription` כדי שתדעו כמה נשאר.
- Requires `ELEVENLABS_API_KEY`; ללא מפתח הכפתור יישאר כבוי.

## 🎥 הגדרת Vertex AI (עבור Imagen 4 ו-Veo)

כדי להשתמש במודלים המתקדמים ליצירת תמונות (Imagen 4) ווידאו (Veo), יש לבצע הגדרה חד-פעמית בחשבון ה-Google Cloud שלך.

> **שים לב**: מודלים אלו דורשים הגדרת חשבון תשלום (Billing) פעיל, גם אם אתם משתמשים בקרדיט חינם.

### שלב 1: הגדרות ב-Google Cloud Console

1. היכנסו לפרויקט שלכם ב-[Google Cloud Console](https://console.cloud.google.com/).

2. **Billing**: ודאו שהפרויקט מקושר לחשבון תשלום פעיל (תחת התפריט "Billing").

3. **הפעלת API**: חפשו בשורת החיפוש `Vertex AI API` ולחצו על **Enable**.

4. **Model Garden**:
   - גשו ל-**Vertex AI** > **Model Garden**.
   - חפשו את `Imagen` ודאגו לאשר את תנאי השימוש (Enable/Agree) אם מתבקש.
   - חפשו את `Veo` ובצעו את אותו הדבר.

### שלב 2: עדכון קובץ ה-.env

אין צורך במפתח API חדש. השתמשו במפתח ה-Gemini הקיים, אך הוסיפו את הגדרות המודלים:

**הגדרה ב-.env:**
```env
# --- Visual Generation Settings ---

# בחרו את מצב היצירה:
# hybrid = השילוב המומלץ (תמונות AI + אנימציות קוד + וידאו)
VISUAL_GENERATOR=hybrid

# בחירת מודלים (Vertex AI):
IMAGEN_MODEL=imagen-4.0-generate-001
VEO_MODEL=veo-2.0-generate-001

# כמות תמונות ליצירה בפרויקט
IMAGE_COUNT=5

# הערה: המערכת משתמשת ב-GEMINI_API_KEY שהוגדר למעלה.
# ודאו שהפרויקט המשויך למפתח זה מוגדר עם Vertex AI API פעיל.
```

**מה-GUI:** לחצו על "🎨 הגדרות ויזואליים" בבאנר העליון.

קבצי הפלט נשמרים תחת `outputs/<תאריך>_<שם_הרצאה>/`.

## פתרון בעיות נפוצות
| תקלה | סיבה אפשרית | פתרון |
|------|--------------|--------|
| 401 Unauthorized | מפתח שגוי או endpoint לא נכון | בדקו את ההגדרות ב-`.env` |
| 404 DeploymentNotFound | שם פריסה לא תואם | העתיקו מחדש את שם הפריסה מתוך Azure Portal |
| FFmpeg missing | FFmpeg לא מותקן/ב-PATH | התקינו `choco install ffmpeg` או הוסיפו ל-PATH ידנית |
| קובץ בעברית לא נקרא | קובץ אינו UTF-8 | שמרו את הקובץ מחדש ב-UTF-8 |
| אודיו לא מסונכרן | חלק מהסגמנטים לא נוצרו | הריצו עם `--force` |
| הגדרות לא נשמרות | בעיית הרשאות | בדקו הרשאות כתיבה לתיקיית config |
| קריסה בהפעלה (`chat_background_path`) | קובץ UI ישן עם מפתח לא מוכר | מחקו `config/ui_prefs.json` (ייבנה מחדש) או הסירו את המפתח החריג. החל מ־v3.1.4 המפתח מתעלם אוטומטית |

## יצירת קובץ EXE
ליצירת קובץ הפעלה עצמאי (ללא צורך ב-Python):

```bash
# הפעילו את הסקריפט
build_exe.bat
```

הקובץ ייווצר בתיקייה `dist/MBS_Studio/MBS_Studio.exe`

**דרישות להפצה:**
- העתיקו את כל תיקיית `dist/MBS_Studio` למחשב היעד
- ודאו שקובץ `.env` קיים עם מפתחות Azure
- FFmpeg חייב להיות מותקן במחשב היעד
