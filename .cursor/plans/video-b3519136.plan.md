# Video Creation Verification

1. **Prep environment & inputs** – Confirm `.env` and FFmpeg availability, review `pyproject.toml` for required extras, and craft minimal `data/sample_transcript.txt` + `data/sample_metadata.json` so the CLI can run end-to-end without touching user assets.
2. **Baseline pipeline dry-run** – Execute `python -m scripts.generate_podcast ... --dry-run --include-visuals` to surface missing config quickly while keeping `src/pipeline/runner.py` wiring untouched; inspect console/log output for early warnings.
3. **Full video run** – Rerun `scripts/generate_podcast.py` without `--dry-run`, forcing visuals (`--include-visuals --force`) so `VideoComposer` (`src/visuals/video_composer.py`) actually renders against the generated audio; monitor `outputs/<date>_<topic>/processing_log.txt` for errors.
4. **Validate artifacts** – Inspect the produced `final_video.mp4` (size, codec, duration via `ffprobe`), ensure accompanying audio/story files exist, and confirm `outputs/history.json` recorded the run.
5. **Summarize findings** – Capture any failures (missing env keys, moviepy errors, etc.) plus suggested fixes so the user knows whether video creation is healthy or what broke.
